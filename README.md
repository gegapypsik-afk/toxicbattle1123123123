# Toxic Battle — Discord-бот

Бот для **Toxic Battle** — пространства, где можно неформально пообщаться,
пошутить, немного потоксичить и выпустить пар. Первая версия умеет принимать
заявки участников и даёт администраторам панель управления.

> ⚠️ Уважайте других участников и правила общения ^^

## Команды

| Команда    | Что делает                                                                 |
| ---------- | -------------------------------------------------------------------------- |
| `/помощь`  | Показывает описание Toxic Battle и список команд.                          |
| `/battle`  | Открывает форму регистрации: **никнейм**, **возраст**, **опыт участия**.   |
| `/admin`   | Админ-панель (доступна администраторам и настроенным ролям).               |

### Админ-панель `/admin`

- **⚙️ Настройка ролей** — выбрать роли, которым разрешён доступ к панели.
- **📢 Канал регистраций** — выбрать канал, куда бот публикует новые заявки.
- **📋 Заявки** — посмотреть поданные заявки.

Доступ к панели есть у серверных администраторов и у участников с ролями,
выбранными в разделе «Настройка ролей».

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите DISCORD_TOKEN
python bot.py
```

Переменные окружения:

- `DISCORD_TOKEN` — токен бота (обязательно).
- `GUILD_ID` — ID тестового сервера для мгновенной синхронизации команд
  (необязательно; без него команды регистрируются глобально и появляются
  в течение ~1 часа).

## Настройка бота в Discord

1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications).
2. Во вкладке **Bot** нажмите **Reset Token** и скопируйте токен в `DISCORD_TOKEN`.
3. Во вкладке **OAuth2 → URL Generator** выберите scope `bot` и `applications.commands`,
   пригласите бота на сервер по сгенерированной ссылке.
4. Привилегированные интенты **не требуются** — бот работает на слэш-командах.

## Деплой на Railway

1. Подключите этот репозиторий к новому проекту на [Railway](https://railway.app).
2. В разделе **Variables** добавьте `DISCORD_TOKEN` (и при желании `GUILD_ID`).
3. Railway использует `Procfile` и запускает процесс `worker: python -u bot.py`.

> 💾 Файловая система на Railway эфемерна: `data/*.json` обнуляется при
> каждом деплое. Чтобы заявки и настройки сохранялись, примонтируйте
> **Volume** к каталогу `data/`.

## Структура проекта

```
bot.py            # точка входа, загрузка расширений и синхронизация команд
storage.py        # хранилище настроек и заявок на JSON-файлах
cogs/
  general.py      # /помощь
  battle.py       # /battle + форма регистрации
  admin.py        # /admin: панель, настройка ролей и канала, просмотр заявок
Procfile          # команда запуска для Railway
requirements.txt  # зависимости
```
